# Contributing to SearchJet Laravel Package

Thank you for considering contributing to the SearchJet Laravel package! We welcome contributions from the community.

## How to Contribute

### Reporting Bugs

If you discover a bug, please create an issue on GitHub with:

- A clear, descriptive title
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Your environment (PHP version, Laravel version, etc.)

### Suggesting Enhancements

We welcome suggestions for new features or improvements. Please create an issue with:

- A clear description of the enhancement
- Why this enhancement would be useful
- Any potential implementation ideas

### Pull Requests

1. Fork the repository
2. Create a new branch for your feature (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Write or update tests as needed
5. Ensure all tests pass (`composer test`)
6. Format your code (`composer format`)
7. Commit your changes (`git commit -m 'Add amazing feature'`)
8. Push to your branch (`git push origin feature/amazing-feature`)
9. Open a Pull Request

### Coding Standards

- Follow PSR-12 coding standards
- Write clear, descriptive commit messages
- Add tests for new features
- Update documentation as needed
- Use Laravel best practices
- Run `composer format` before committing

### Running Tests

```bash
composer test
```

### Code Coverage

```bash
composer test-coverage
```

### Code Formatting

```bash
composer format
```

## Development Setup

1. Clone the repository
2. Install dependencies: `composer install`
3. Copy `.env.example` to `.env` and configure
4. Run tests to ensure everything works: `composer test`

## Questions?

If you have questions about contributing, feel free to:

- Open an issue for discussion
- Email us at support@searchjetengine.com

## Code of Conduct

Please be respectful and considerate in all interactions. We aim to foster an inclusive and welcoming community.
