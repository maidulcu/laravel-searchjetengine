# Security Policy

## Reporting Security Vulnerabilities

**Do NOT report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please email:
**security@searchjetengine.com**

Include:
- Description of the issue
- Steps to reproduce (if applicable)
- Potential impact

We take all security reports seriously and will:
- Acknowledge receipt within 48 hours
- Provide an update on progress
- Credit you in the fix (optional)

## Supported Versions

| Version | Status |
|---------|--------|
| 1.x     | Actively maintained |
| < 1.0   | No longer supported |

## Security Best Practices

When using this package:
- Keep Laravel and dependencies updated
- Store API keys in environment variables
- Use HTTPS for all API communication
- Validate user input before search operations
- Monitor API quota usage

## Responsible Disclosure

We follow responsible disclosure practices:
1. Issues are reported privately
2. Fixes are developed and tested
3. Releases are coordinated
4. Users have time to update
5. Advisories are published after fixes are available
